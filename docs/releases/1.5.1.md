# 1.5.1: install.sh installs this repository; setup.sh is now install-all.sh

The Latest release, after [1.5.0](1.5.0.md). The converter's code is unchanged; only the install scripts and their docs changed.

## What changes
- **`install.sh`** (new) installs this repository only: the `edgeconnect-preconfig` command and its agent skill. It runs `install-all.sh` with this repository picked and passes every other option through (`--yes`, `--agents`, `--dir`, `--skills`, `--mcp`); it refuses `--repos`.

  ```bash
  bash <(curl -fsSL https://raw.githubusercontent.com/Crypto-Gi/edgeconnect-preconfig/main/install.sh)
  ```
- **`install-all.sh`** is the old `setup.sh`, renamed, and asks which of the three EdgeConnect repositories to install. It is the same file in all three repositories, behaves as before, and still recognises the commands and the `AGENTS.md` it wrote under its old name.
- **`setup.sh`** still works: it prints that it is now `install-all.sh` and runs it, so old links and re-runs keep working.
- No other changes.

## Update
Run `install.sh` (or `install-all.sh`, or the old `setup.sh`) again in the install folder.

## Checked
- Full offline suite: 738 tests pass.
- `tests/test_installers.py`: `install.sh` adds this repository's number and passes the other options through, from a clone and when downloaded; it refuses `--repos`; `setup.sh` forwards to `install-all.sh`.
- A live `install.sh` run into an empty folder installed only this repository; its command printed its version and the skill was `SKILL.md` only.

## Not checked
